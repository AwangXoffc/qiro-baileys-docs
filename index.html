Need to know

Frequently asked questions.

Is Qiro Baileys an official WhatsApp or Meta SDK?

No. Qiro Baileys is an unofficial community distribution based on the Baileys project. It is not affiliated with WhatsApp, Meta, or the upstream maintainers.

Should I install latest or next?

Use the default installation for the version assigned to latest. Use @next when you intentionally want the prerelease channel. Check the npm versions page before choosing.

Are Qiro interactive extensions production-stable?

The helpers described here are experimental. Their behavior can vary across WhatsApp clients and release versions. Verify the exports and test with a separate account before production use.

Where can I find the full API guide?

Start with the API index preserved in the package README. For Baileys core behavior, also consult the upstream repository and documentation.

What Node.js version do I need?

The package declares Node.js 20.0.0 or newer in its engine requirement.
